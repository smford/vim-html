Vim & Linux Shell Quick Reference

Navigation

  • h j k l — Left, Down, Up, Right
  • w / b — Jump word forward / backward
  • e / ge — Jump to end of word forward / backward
  • 0 / $ — Jump to start / end of line
  • ^ — Jump to first non-blank character
  • gg / G — Go to first / last line
  • <N>G / <N>gg — Jump to line N (e.g. 42G)
  • { / } — Jump paragraph backward / forward
  • Ctrl+d / Ctrl+u — Half-page scroll down / up
  • Ctrl+f / Ctrl+b — Full-page scroll down / up
  • % — Jump to matching bracket (), {}, []

Editing & Operators

  • x / X — Delete char under / before cursor
  • r<char> — Replace single character under cursor
  • dd / <N>dd — Delete (cut) line / N lines
  • dw / de / d$ / d0 — Delete word / to end / to start
  • yy / <N>yy — Yank (copy) line / N lines
  • yw / y$ — Yank word / to end of line
  • p / P — Paste after / before cursor
  • u — Undo last change
  • Ctrl+r — Redo last undone change
  • . — Repeat last edit action
  • J — Join current line with next line
  • >> / << — Indent / unindent line
  • ~ — Switch character case (upper/lower)

Entering Insert Mode

  • i — Insert before cursor
  • I — Insert at beginning of line
  • a — Append after cursor
  • A — Append at end of line
  • o — Open new line below and insert
  • O — Open new line above and insert
  • s — Delete char and enter insert mode
  • S / cc — Clear entire line and insert
  • cw / ciw — Change word / change inside word
  • C — Change to end of line
  • R — Enter Replace mode
  • Esc / Ctrl+[ — Return to Normal mode

Visual Mode (v / V)

  • v — Start character-wise visual selection
  • V — Start line-wise visual selection
  • d / x — Cut selected text
  • y — Yank (copy) selected text
  • c — Change selected text (delete & insert)
  • > / < — Indent / unindent selected block
  • u / U — Convert selection to lowercase / UPPERCASE
  • ~ — Toggle case of selection
  • Esc — Exit visual mode back to normal

Saving, Exiting & Downloading

  • :w — Save current buffer to virtual filesystem
  • :w <filename> — Save as specific filename
  • :q — Quit buffer (warns if unsaved changes)
  • :q! — Force quit buffer without saving
  • :wq / :x / ZZ — Save and quit
  • :download or :export — Download current file directly to your computer
  • :w !download — Vim-style download pipeline
  • :r <file> — Read contents of another file into buffer

Search, Substitute & Options

  • /pattern — Search forward for text / regex
  • ?pattern — Search backward
  • n / N — Next / previous search match
  • :noh — Clear search highlighting
  • :%s/foo/bar/g — Replace all instances of foo with bar
  • :s/foo/bar/g — Replace in current line only
  • :<number> — Jump to line number (e.g. :25)
  • :set nu / :set nonu — Toggle line numbers
  • :set rnu / :set nornu — Toggle relative line numbers
  • :set wrap / :set nowrap — Toggle line wrap
  • :! <command> — Execute terminal command (e.g. :!ls)

File & Directory Management

  • vim <file> / vi <file> — Open or create file in Vim
  • ls / ls -la / ls -l — List files with metadata/hidden
  • tree — Display directory tree hierarchy
  • cd <dir> / cd .. / cd ~ — Change directory
  • pwd — Print current working directory
  • mkdir <dir> / mkdir -p — Create directory
  • touch <file> — Create empty file or update timestamp
  • cat <file> — Display file content
  • rm <file> / rm -r <dir> — Remove file or directory
  • cp <src> <dst> — Copy file
  • mv <src> <dst> — Move or rename file

Pipes, Redirection & Utilities

  • echo "text" > file.txt — Write text to file
  • echo "text" >> file.txt — Append text to file
  • grep <keyword> <file> — Search for pattern
  • download <file> — Download file to local machine
  • clear / Ctrl+L — Clear terminal output
  • history — Display recent command history
  • whoami / uname -a / date / uptime
  • top / htop / ps aux — View system processes
  • df -h / free -m — View storage and memory
  • dmesg / journalctl — View kernel & system logs
  • reboot — Restart Linux boot simulation

How to Download Files

  1. Inside Vim: Type :download or :export or :w !download and press Enter.
  2. In Terminal: Run download <filename> (e.g. download server.py).
  3. Top Navigation Bar: Click the Download button anytime while editing a file, or click Export VFS to download your entire filesystem state as a JSON backup.
  4. Upload Files: Drag & drop files onto the browser window or click Upload in the top bar to place them right into your current virtual directory!
Tip: Press Tab in terminal for command and filename autocomplete.
